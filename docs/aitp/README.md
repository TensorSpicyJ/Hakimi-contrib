# AITP retirement record

> **Historical record.** Hakimi's former AITP adapter and Research Mode were retired. This directory preserves implementation and compatibility evidence; it is not an operating guide.

## Current boundary

AITP may be installed independently as a Skill-only plugin. Hakimi discovers it through the ordinary plugin, system-prompt, and `Skill` tool path, like other plugins. Where an installer is needed, use the stable curated archive: <https://github.com/bhjia-phys/AITP-Research-Protocol/releases/download/v1.1.0/aitp-1.1.0.zip>.

Hakimi provides no AITP CLI, ledger adapter, session hook, Research Mode, automatic write, special plugin handling, or custom AITP tool family. The plugin's own Skill instructions and external documentation define its behavior.

## Preserved historical evidence

The tracked records in this directory document the former adapter's contracts, design, rollout status, and planned method-distillation work. They are retained for audit and migration context only:

- `compatibility-matrix.md` — former compatibility decisions.
- `TRACKING.md` — dated historical status observations.
- `unified-research-mode-program.md` — retired implementation program.
- `theory-research-agent-design.md` — retired design memo.
- `method-distillation-orchestration.md` — retired proposal.

No file in this directory commits, modifies, or claims to modify an external AITP checkout.
