# Hakimi × AITP compatibility matrix — retired record

> **Historical record.** This matrix describes the legacy Hakimi AITP adapter and Research Mode. Both were removed and this file is no longer a live compatibility contract.

## Historical baseline

Prior entries recorded AITP contract and fixture observations, including the 2026-08-23 committed AITP revision `eae1bce5eba367a5f6db6ba73ff0912dd3a5e290`. Those observations must not be read as a current release, installation recommendation, or integration promise.

## Retirement outcome

Hakimi no longer exposes the adapter, AITP command or ledger path, research REST endpoints, SDK or klient APIs, model tools, Research Board, Research Manager, events, or `/research`. There is no current Hakimi-side compatibility matrix to maintain.

AITP remains independently installable as an ordinary Skill-only plugin. Its use follows the normal Hakimi plugin discovery, system-prompt, and `Skill` tool path; it receives no special runtime integration. This record does not modify an external AITP checkout.
