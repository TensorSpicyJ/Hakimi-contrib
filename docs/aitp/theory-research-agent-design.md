# AITP × Hakimi theoretical-physics research agent design — retired record

> **Retired.** This memo described the legacy Hakimi AITP adapter, Research Mode, and research-agent design. Those product capabilities were removed; the document is retained as historical design evidence only.

## Historical boundary

The former design separated scientific judgment, human review, and durable evidence from UI and runtime mechanics. It also recorded why a product should not silently infer scientific conclusions or substitute a local ledger for an external protocol.

## Retirement outcome

Hakimi no longer implements the adapter, research state or loop, mode controls, `/research`, model tool family, public research APIs, Research Board, or Research Manager. It makes no AITP writes and has no AITP session hook.

The current AITP relationship is ordinary Skill-only plugin collaboration through standard plugin discovery, system-prompt visibility, and the `Skill` tool. This memo contains no live checklist, implementation promise, or claim that an external AITP checkout was modified.
