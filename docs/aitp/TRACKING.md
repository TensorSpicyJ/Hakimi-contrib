# AITP status tracking — retired record

> **Historical record.** The entries previously kept here tracked the legacy Hakimi AITP adapter and Research Mode. They are superseded by retirement and are retained only as audit context.

## Recorded conclusion

The former integration included an adapter, a research workflow, public transport surfaces, and TUI/Web controls. Those Hakimi capabilities were deliberately removed. Do not treat earlier stage labels, checklists, test counts, feature flags, or planned work as active commitments.

## Current boundary

AITP is now only an independently installable Skill-only plugin. Hakimi handles it through ordinary plugin discovery, the system prompt, and the `Skill` tool. Hakimi has no AITP CLI, ledger adapter, session hook, Research Mode, automatic persistence, special handling, or custom tool family.

This historical record does not claim that an external AITP checkout was changed.
