# Hakimi × AITP unified Research Mode program — retired record

> **Retired.** This document formerly specified a finite implementation program for Hakimi Research Mode. The program is not active: its runtime, adapter, transport, model tools, TUI/Web controls, and Research Loop were removed.

## Historical value

The program recorded design constraints for a bounded research workflow, explicit human review, evidence handling, and separation between product state and an external ledger. These are historical engineering evidence, not current product behavior or a future implementation plan.

## Current boundary

Hakimi has no AITP-specific runtime or orchestration. AITP can be independently installed as a Skill-only plugin and is discovered through Hakimi's ordinary plugin, system-prompt, and `Skill` tool path. This record neither changes nor makes claims about an external AITP checkout.
